# TSP NEWS – Tamil Frontend v2

தமிழ் வாடிக்கையாளர்களுக்காக மாற்றப்பட்ட responsive news frontend.

## முக்கிய அம்சங்கள்
- தமிழ்-first UI
- PC / Laptop / Tablet / Android / iPhone responsive
- முகப்பு, செய்திப் பிரிவு, article, search pages
- மயிலாடுதுறை மாவட்ட focus
- மாதிரி தமிழ் செய்தி data
- பின்னர் Python + Django + PostgreSQL API-க்கு connect செய்ய தயாரான structure

## Run
`index.html`-ஐ browser-ல் திறக்கவும்.
VS Code-ல் Live Server பயன்படுத்தலாம்.
